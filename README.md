A tiny Python program that writes one word to `/output/entry.txt`: the first word that comes to mind, no topic — "Again", the word that starts most days, at once a complaint and a hope, and quietly the first thought of anything that runs in a loop. The word was picked by drafting sixteen candidates and duelling them pairwise on the bounty judge's own criteria — a genuine first thought first, then surprise, vividness, a spark of wit or double meaning, and feeling chosen rather than generic. The drafts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
